
# Marriage Connect

Marriage Connect is a full-stack wedding marketplace for India.

It connects customers and wedding vendors through vendor profiles,
location-based search, quotations, availability, bookings,
payment records, and reviews.

## Version 1 Technology Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI
- SQLAlchemy ORM
- Psycopg

### Database
- PostgreSQL

### Authentication
- Argon2id password hashing
- JWT access tokens
- Rotating refresh tokens

### Development Tools
- Git and GitHub
- VS Code
- Alembic for database migrations
- Pytest for backend testing

## User Roles

- Customer
- Vendor
- Administrator

## Core Features

1. User registration and authentication
2. Vendor registration and approval
3. Vendor profiles and service listings
4. Vendor search and location filtering
5. Quotations and availability
6. Booking management
7. External payment-proof records
8. Booking confirmation PDFs
9. Reviews and administration

## Development Approach

- Version 1: Full-stack MVP
- Version 2: Advanced system design and optimization
- Version 3: Distributed architecture and scaling
